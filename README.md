# School Transport Management System - DevOps CI

## Project Description

This project is a simplified implementation of a School Transport Management System.

The application manages students, buses, bus capacity, and student transport allocation.

## Features

- Create student records
- Create buses with capacity
- Add students to buses
- Check bus capacity
- Allocate students to buses
- Run automated unit tests

## Technologies Used

- Python
- Git
- GitHub
- Jenkins
- Python unittest
